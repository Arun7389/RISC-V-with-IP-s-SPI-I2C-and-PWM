## 1. Executive Summary

This document specifies the exact physical and protocol-level connections between the five subsystem Universal Verification Methodology (UVM) Verification Intellectual Properties (VIPs) and the actual RISC-V System-on-Chip top module (`soc_top.sv`).

The system integrates:
1. **GPIO VIP** (32-bit bidirectional I/O)
2. **I2C VIP** (Open-drain Master/Slave bus)
3. **PWM VIP** (Pulse-width modulation output)
4. **SPI VIP** (Full-duplex serial peripheral interface)
5. **UART VIP** (Asynchronous receiver/transmitter)

## 3. Signal Integrity and Bus Contention Avoidance

1. **Floating Input Elimination**:
   - `uart_rx_i` is driven to a default logic 1 (quiescent idle state) by the UART VIP driver.
   - `spi_miso_i` is driven to logic 0 by the SPI VIP driver when CS is deasserted.
   - `gpio_io[31:0]` is tri-stated when VIP output enable is zero, preventing multi-driver conflicts when DUT drives output, and driven solidly when VIP acts as stimulus.
2. **Open-Drain Modeling**:
   - Both `i2c_scl_io` and `i2c_sda_io` feature Verilog `pullup` primitives.
   - The I2C VIP driver only drives `1'b0` when active, and releases to `1'bz` when idle or high, faithfully adhering to the I2C physical layer specification.
3. **No Duplicate Drivers**:
   - All unidirectional outputs from the DUT (`uart_tx_o`, `spi_clk_o`, `spi_cs_n_o`, `spi_mosi_o`, `pwm_out_o`) are connected exclusively to VIP inputs.
